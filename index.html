      GPS traces

      Where people actually run: public running-pace GPS traces from OpenStreetMap, so the search can favour paths that are really run rather than merely mapped.

      Downloads the public GPS traces people have uploaded to OpenStreetMap around the start marker, keeping only the points recorded at a running pace (3–11 min/km), so the search can favour paths that are really run rather than merely mapped. Only traces uploaded with their timestamps can be told apart from a drive or a bike ride, so most of what arrives is discarded — and this takes a long time: the API hands out 5 000 points at a time, one ~2 km box after another. Minutes for a small radius, far longer for a big one. Cancel stops it, and then nothing is saved. Uses the same area radius as above.
